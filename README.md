# 婺需文学社

> 以诗会友，以文养心。
> 愿旧诗与新声，都有人听。

社中诸友，聚四地而同人，寄文墨于一方。此站为文学社之网上会所：录诗、词、曲、赋、文，辑之以期，系之以概念，期与期相承，人与文相见。凡社中同人，皆可来稿；稿经编委审阅，辑录成篇。

- 公开站点：<https://wuxu-literary.netlify.app>
- 微信公众号：**婺需文学社**（同名）
- 想投稿，不必懂代码：网页「投稿」一页填表即可，稿至编委案前，审后即刊。

## 站中所藏

**诗文稿**——四十五篇原创作品，诗、词、联句、古风、曲、赋、散文兼有。每篇单独成页，页中附作者、分部、体裁，及关联诸作（同作者、同意象、同时同源），每次开页随机呈现、可换一批；全站另有《全文源库》备检。

**刊期档案**——作品按"期"辑录，一期一会：

| 期 | 性质 | 所收 |
|---|---|---|
| 甲辰清明雅集 | 雅集 · 首聚当日同题 | 七篇，社长为序 |
| 回忆文会《时间溯流》 | 文会（公众号） | 九篇 |
| 九月投稿辑 | 投稿辑 | 两篇 |

未入辑者，皆存"散作"，待攒而成期。

**概念档案**——跨期之题，如「清明」「立社」，各成一页，收录相关篇目；题解虚位，俟社里共叙后补。
