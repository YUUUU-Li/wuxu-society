## 第一步
将仓库克隆于本地：
```bash
git clone https://github.com/YUUUU-Li/wuxu-society.git
``` 

若本地已经存在仓库：
```bash
cd D:/wuxu-society (示例，你的仓库路径)
git pull
```

## 第二步
开启分支并切换到该分支：
```bash
git checkout -b dev
```
> (dev是分支名，也可以改成"fenzhi")

如果需要切换回原分支：
```bash
git branch main
```
## 第三步
**快乐vibe coding**

## 第四步
提交修改：
```bash
git add xxx
git commit -m "提交时候的附带信息，一般是对做了什么修改的说明"
```

## 第五步
合并分支：
```bash
git merge dev
```
> (dev是分支名)

## 第六步
推送修改：
```bash
git push
```
