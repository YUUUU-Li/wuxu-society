# 众注系统方案（P1 · 标签 + 评论 + 归纳回流）

> **状态（2026-09）**：版式原型 ✅（`/proto-note.html`，交互均已演示）；打分算法 ✅ 暂定"余弦归一"；
> 后端待 Cloudflare Pages + D1 落地后实现 MVP。本文记录已拍板设计，供实现与后续讨论。

## 1. 定位

作品页正文之下的"众注"区，把两件事合在一起：

1. **读者/社友共注**：评情感、评意象、评好句——**人**的判断（不用 AI 猜）；
2. **归纳回流**：大家的标注沉淀为数据，反哺作品的意象/关联归纳，修正"AI 见'雨''风'即意象"的粗疏。

## 2. 版式（自上而下，见原型页）

```
【作品正文】
───────────────
标签（你认为的本作品亮点）· 点一下即赞同，可再点取消
  [思念 6] [明月 5] [重逢 3] [春景 2·已点] [怅惘 2] [用典 1]
  ⬜ 输入标签：同名/相似即选中匹配，没有再新建        [添加]
   （联想只推“本页还没展示”的候选；无匹配=新建候选，编委采纳后转正）
────────────────
评论 · 楼式，笔名/昵称制（游客亦可评）
  1楼  泊珩 · 2026-09-09   「当时明月在…」(引文块)
        ……评论正文……            [同感 3 ·泊珩/济枫/cty] [回复 · 2]
           └ 回帖(单层楼中楼): 昵称 · 时间 · 回复 泊珩（#1）
  2楼  …
  笔名/昵称 [____]   正文(支持行首 > 引文；网址自动成链接) [发表]
────────────────
（标签票数攒到阈值 → 候选标签 → 编委采纳 → 进作品意象/相似标签关联）
```

- 标签 pill 计数即时增减；被点中的 pill 朱砂实心；
- 回帖为**单层楼中楼**（不做无限嵌套），每条回帖标注"回复 XX（#楼号）"；
- 评论区与回帖都只支持：换行、行首 `>` 引文块、http(s) 自动链接；**不做完整 Markdown**（安全 + 风格统一）。

## 3. 标签机制

- **联想池**：系统池（社里维护）+ 已被赞标签 + 候选标签；输入即时过滤，**排除本页已展示项**，最多列 6 条，超出滚动；
- **点选联想/输入命中 = 赞同该标签**（计数 +1），绝不产生重复标签；
- **无匹配新词** = 新建"候选标签"（虚线样式），进入候选池等待编委采纳/合并/删除；
- 远期（账户系统后）：游客署名可演进为匿名制，字段层已独立。

## 4. 归纳回流与"同标签"关联排序

**回流链**：标签票数 → 候选标签 → **编委采纳** → 作品元数据（意象/标签）→ 相似标签关联。
（防止用户自定义标签五花八门污染数据：自定义只进候选，转正必经编委。）

**"同标签"关联打分（暂定：余弦归一）**——候选作品按与当前作品标签票数向量的余弦相似度排序：

```
A·B（点积）= Σ 共享标签票A × 票B          —— 只算两边都有的标签
|A| = √(Σ票A²)，|B| = √(Σ票B²)
相似度 = (A·B) / (|A| × |B|)
```

- **点积的毛病**（弃用原因）：票多的作品恒胜、冷门被埋——如 A（思念6·明月5·重逢3）候选 B（思念9·重逢2）=60 vs 候选 C（明月20）=100，C 胜出但主题远不如 B 贴合；
- **余弦**先各自"除以长度"，比的是**票的分配形状**而非总量：上例 B≈0.78 > C≈0.60；再加冷门 D（思念5·重逢2）=0.80 反而最高——**票少但主题完全同向的冷门作品不会被埋**；
- **冷启动**：票数为 0 时以现有意象字段按"每标签 1 票"参与，行为≈旧逻辑；票来了自动加权；
- **分组次序不变**：强关联（首位）→ 同作者 → 同标签 → 同源；分数相同随机排；
- 待定细节：同标签入选下限（如至少共享 2 个标签）、展示条数、是否把现有分组名"同意象"改称"相似标签"。

## 5. 技术路线（随 Cloudflare Pages + D1）

| 层 | 方案 |
|---|---|
| 存储 | CF **D1**（免费 SQLite）：表 `tag_votes(work_id, tag_id, vote_count)`、`comments(work_id, name, body, created_at, reply_to)`、`tags(id, word, kind[预设/候选/已采纳])`、`likes` 去重计票（先显后删或先审后显，见待拍板） |

| 接口 | Pages Functions：`POST /submit-tag`（幂等点赞/取消）、`POST /comment`（评论/回帖）、`GET /zhuzhu?work=`（标签+评论 JSON）；限流 + 蜜罐 |
| 关联排序 | 作品页加载时 `GET /related`（服务端算余弦）或构建期缓存票数；**无票回退现有静态关联** |
| 安全 | 昵称与正文转义；行首 `>` 引文、http 链接白名单；无 raw HTML；敏感词/先审后显开关待定 |

> **时区约定**：库里 `created_at` 一律存 **UTC**（D1 `datetime('now')` 原生行为）；接口读取时统一转为**北京时间（+08:00）**返回，页面直接显示。切勿改成存本地时间，否则跨时区读者与将来迁移都会错乱。

## 6. 待拍板（已定 ✓ / 待定）

1. **审核模式**：✅ **先显后删 + 编委可删**（社内流量小，即时热闹优先）；编委在作品页众注区通过「编委」入口输入钥匙即出现逐楼删除按钮（钥匙存 CF 环境变量 `ZHUI_ADMIN_KEY`，只存浏览器会话）；删除为软删除，**被回复的已删楼显示「该楼已删」占位、不可跳转**。
2. **同标签入选下限与条数**：✅ **共享下限 2**（候选须与该作品共享 ≥2 个标签才入组）+ **展示 4 篇**（保留"换一批"随机，样式同现有分组）；
3. **改名**：✅ "同意象"分组 → **"相似标签"**（随标签体系接入作品页时一并改名，旧逻辑先沿用）；
4. 预设/候选标签初始清单：⏳ 再说（社里共拟）。
