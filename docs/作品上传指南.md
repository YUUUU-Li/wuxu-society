# 作品投稿指南（给投稿人）

> 最简单的方式是**网页直接投稿**（下面 §1），不需要懂任何代码。
> 会一点 Git/Obsidian 的编委，也可以在仓库里直接编辑作品（§2）。

---

## 1. 网页投稿（推荐 · 人人可用）

1. 打开网站 → 顶部导航「**投稿**」（手机端点右上 ☰ 菜单里的投稿）；
2. 填写：
   - **题名**（必填）、**署名**（笔名/姓名缩写，如 `zk（道格）`）；
   - **体裁**：诗/词/联句/古风/曲/赋 等选"诗句类"；散文/小说选"散文类"——决定自动排版；
   - **正文**：
     - 写好后点正文框右侧的 **「预览」**，立即按发布版式渲染（预览即所见即所得）；
     - 点正文框上方的 **「示例」** 可填入一段覆盖全部排版功能的范例，照着改最快；
     - 诗句：**每行一句、句间自然换行**；段与段之间空一行；
     - 散文：自然分段，段间空一行；
     - **行首标记（可选，照写即可）**：
       - `&` 开头 → **楷体文段**（前记/后记/序/跋），如 `&后记：丙午年四月二十，芒种作。`
       - `>` 开头 → **引文块**（楷体 + 朱砂竖线），多行连写
       - 单独一行 `---` → **分割线**
     - 含"自序/后记"等散文段：**不写 `&` 也可以**，段首写 `自序：` 或 `后记：` 会自动按楷体排版；
     - 含赏析/评：段首写 `评（署名）：` 或 `注：`，会按赏析块排版；
   - **摘句（选填）**：一句最想展示的话，用于首页卡片；不填则自动取正文首句；
   - **意象（选填）**：逗号分隔，如 `雨, 离别`；
   - **出处（选填）**：属于某次雅集/公众号文会就填上；
   - **文件标识（选填）**：小写拼音/英文，会成为网页地址（如 `zhuyingtai`）；不填自动生成；
   - **给编委的附言（选填）**：第几稿、是否匿名等，**仅编委可见，不会发布**；
3. 提交 → 系统自动开审稿单（PR）→ **编委审核后合并，即自动上线**。

> 投稿后一般几天内会有编委答复；如需改稿，重新提交并在附言里说明是第几稿即可。

## 2. 编委直接编辑已有作品（本地）

仓库即 Obsidian 库（`D:/wuxu-society`）：

1. 每篇作品 = `src/works/<文件名>.md`，文件头 `---` 之间是信息（题名/署名/体裁/意象/摘句…），下方是正文；
2. 正文每段一个 HTML 段落：
   - 诗句 `<p class="stanza">第一句<br />第二句</p>`
   - 楷体序文 `<p class="stanza kaiti">…</p>`　散文 `<p class="prose">…</p>`
   - 赏析 `<p class="analysis">…</p>`　落款 `<p class="byline">…</p>`　分节线 `<hr class="lib-hr" />`
3. 改完回到仓库目录执行：
   ```bash
   npm test                                   # 全量回归
   git add -A
   git -c core.autocrlf=false commit -m "改了什么"
   git -c http.proxy=http://127.0.0.1:7890 -c http.sslBackend=openssl push origin main
   ```
4. 等 1–2 分钟，线上生效。

> 细节（字段表、新增作品登记、分组/期、样式改法）见《网站自定义指南》与《编委操作手册》。

## 3. 常见问题

- **想改已发布作品的文字？** 走 §2 本地编辑，或重新网页投稿并在附言里请编委替换；
- **投稿后没反应？** 可能是网络没发出去；刷新重试，或直接联系编委代投；
- **正文格式乱了？** 诗句之间不要空行（空行=分段）；散文每段之间要空行。
