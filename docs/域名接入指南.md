# 自有域名接入指南（Cloudflare Pages）

> 站点现状：**https://wuxu.org** 已接入 Cloudflare Pages，`www.wuxu.org` 与 `wuxu-society.pages.dev` 亦可访问。
> 站点代码全程用相对链接，换域名不需要改任何页面——只在 `src/_data/site.json` 的 `url` 里改一行（sitemap/OG/robots 都读它）。

## 1. 准备

- [ ] 域名（本站为 `wuxu.org`，注册商自管）；
- [ ] Cloudflare 账号，且域名已添加到 Cloudflare（**Active** 状态）；
- [ ] 能登录 Cloudflare 的账号（本站域名与 Pages 均由社长/维护者管理）。

## 2. 把域名绑到 Pages 项目

1. Cloudflare 面板 → **Workers & Pages** → 选项目 `wuxu-society`；
2. **Custom domains** → **Set up a custom domain** → 填 `wuxu.org` → 按提示确认；
3. 再绑一个 `www.wuxu.org`（可选，建议全绑）；
4. Cloudflare 会自动写 DNS 记录（`CNAME`/`A`）并签发 SSL 证书（几分钟内生效）。

## 3. 域名注册商处（仅当域名 NS 未托管在 Cloudflare）

- 到注册商后台把 **NS 改成 Cloudflare 给的两条**（如 `xxx.ns.cloudflare.com`）。
- 旧站遗留的 `A` 记录（历史 AWS IP）与 `_acme-challenge` TXT **全部删除**——CF 绑定自定义域时会自动建正确记录。

## 4. 绑定后收尾

1. `src/_data/site.json` 的 `url` 改成 `https://wuxu.org`（**已改**）；
2. 重新部署：`git push origin main`，Cloudflare 自动构建；
3. 抽查：首页/作品页可开、`/sitemap.xml` 与 `/robots.txt` 里都是新域名。

## 5. 排查

| 现象 | 先查 |
|---|---|
| 打不开/证书错误 | Cloudflare 里域名状态是否 Active；Custom domains 是否已生效 |
| 打开是旧站内容 | 是否仍是旧托管地址；浏览器硬刷新（Ctrl+F5） |
| 页面 404 | Pages 项目构建设置：Build command `npm run build`、Output `dist` |
| 表单/众注不工作 | Pages 项目 → Settings → Functions：D1 绑定名 `DB`、环境变量 `GITHUB_TOKEN_SUBMIT` |

## 6. 常见问题

**Q1：换域名会影响投稿/评论吗？**
不会。投稿与评论走本站 `/api/*` 函数 + GitHub/D1，与域名无关。

**Q2：`pages.dev` 旧地址还要留吗？**
可留作备用入口；若想统一流量，可在 Cloudflare 用 Redirect Rules 把 `pages.dev` 301 到 `wuxu.org`。
