# 域名接入指南（Spaceship 买 → Cloudflare 管理 → 指向婺需站）

> 目标：让网站可以通过**自己的域名**访问（如 `wuxu.example.com`），并且在大陆访问比
> 默认的 `wuxu-literary.netlify.app` 更稳。全程不改网站代码——站点本身是用**相对链接**
> 生成的，任何域名下都能正常打开。
>
> 用时参考：买域名 10 分钟；接入 Cloudflare + 改 DNS + 挂到 Netlify 约 20 分钟；
> 生效等待（DNS 全球同步）通常 1 小时内，最长 24 小时。

---

## 0. 准备清单

- [ ] 已有一个域名（本指南以你在 Spaceship 购买的域名为例，其他注册商步骤同理）；
- [ ] 网站现在的地址：`https://wuxu-literary.netlify.app`（Netlify 站点名 `wuxu-literary`）；
- [ ] 能登录 Netlify 的账号（就是现在管站点的那位朋友，或问他要一次操作窗口）。

> 备案提醒：域名只走**境外**解析/加速（Cloudflare 免费版就是），**不需要 ICP 备案**，买了就能用。
> 域名记得在注册商处开启**自动续费**和 **WHOIS 隐私保护**。

---

## 1. 把域名交给 Cloudflare 管理（拿两个"门牌号"）

1. 注册/登录 [Cloudflare](https://dash.cloudflare.com)（免费版即可）；
2. 首页 → **Add a site** → 输入你的域名 → 选 **Free** 套餐 → Continue；
3. Cloudflare 会自动扫描旧 DNS 记录，照抄保留（现在还没有记录也不怕）；
4. 最后一步会给你**两个 Nameserver**（形如 `ada.ns.cloudflare.com`、`bob.ns.cloudflare.com`）——
   **复制保存**，下一步要用。

## 2. 去 Spaceship 改 Nameserver（把域名"指向" Cloudflare）

1. 登录 Spaceship → 进入该域名的 **DNS / Nameservers** 管理页；
2. 把原来的 Nameserver（Spaceship 默认的两个）**全部替换**成 Cloudflare 给的那两个；
3. 保存。之后等待生效：快则几分钟，慢则 24 小时。Cloudflare 那边显示站点状态从
   *Pending Nameserver Update* 变成 **Active** 即成功（期间不用反复刷新，去做第 3、4 步）。

## 3. 在 Cloudflare 里加两条"路牌"（DNS 记录）

进入该域名 → **DNS → Records**，添加：

| 类型 | 名称 | 内容 | 代理 |
|---|---|---|---|
| CNAME | `@`（主域名，留空即可） | `wuxu-literary.netlify.app` | 开（橙色云） |
| CNAME | `www` | `wuxu-literary.netlify.app` | 开（橙色云） |

说明：
- 主域名用 CNAME 是 Cloudflare 的 **CNAME 展平（Flattening）** 功能，免费版自动支持，不必用 A 记录；
- "橙色云"= 走 Cloudflare 代理（加速 + 免费 SSL + 隐藏源站），保持开启。

## 4. 告诉 Netlify"这个域名归我"

1. 登录 Netlify → 打开站点 `wuxu-literary` → **Domain management**（域管理）；
2. 点 **Add a domain**，依次添加主域名和 `www`（两个都加）；
3. Netlify 会自动为这两个域名申请 SSL 证书（状态变成 HTTPS 可用前属正常）；
4. 如果想把老的 `wuxu-literary.netlify.app` 自动跳到新域名：在 Domain management 里把
   **新域名设为 Primary**，并看老地址能否设置成"重定向"。找不到该选项也没关系——
   两个地址并存无害（站内全是相对链接，不会出现"老链接里混着新地址"的问题）。

## 5. 验证

- 浏览器开 `https://你的域名` 与 `https://www.你的域名`，应看到文学社首页；
- 随便点进一篇作品、投稿页，确认链接都正常；
- Cloudflare 的 **SSL/TLS → Overview** 建议设为 **Full (strict)**（Netlify 端有有效证书）。

---

## 6.（可选）进阶：Cloudflare IP 优选

原理：Cloudflare 默认分配给每个域名的 IP 在大陆有时绕路。**优选** = 手动挑一个到你家
网络延迟低的 Cloudflare IP，把它填到 DNS 记录里（或配合分线路解析），让访问更快。

- **什么时候做**：先正常用几天，如果明显感觉慢再做，不用一开始就折腾；
- **做法概要**：① 用测速工具（网上搜 "Cloudflare 优选 IP 工具"，选一个下载量大的）测出
  本地延迟最低的几个 IP → ② 把主域名记录从 CNAME 改成 **A 记录 + 优选 IP**（保留橙色云，
  `www` 仍用 CNAME）→ ③ 以后 IP 变慢了重复一次即可；
- 家里与学校/不同运营商网络测出的"最优 IP"可能不同，追求极致可配合分线路 DNS（进阶中的进阶）。

## FAQ

**Q1：改完打不开？**
按顺序查：① Cloudflare 域名状态是否 Active；② 两条 DNS 记录是否橙色云；③ Netlify Domain
management 里两个域名是否已加、HTTPS 是否就绪；④ 本机 DNS 缓存（换手机流量试一下最快）。

**Q2：以后想换托管平台（比如不用 Netlify 了）？**
只改 Cloudflare 的 DNS 记录指向新平台即可，**域名、评论、SSL 都不受影响**——这正是买域名的最大好处。

**Q3：以后上评论系统，跟域名有关系吗？**
评论服务（如 Waline）与主站是"两个站点"，各自有自己的地址。届时只需把主站新域名加进评论
服务的允许域名列表（CORS 白名单）即可，属于配置项，不影响这里的一切。

**Q4：会不会影响投稿功能？**
不会。投稿函数走的是 Netlify 内部地址 + GitHub，与域名无关；换域名后投稿页依旧可用。
