## 三、口径提醒（别改乱）

- 作品排序以 `created` 升序为准，未填者不猜日期；口径单一真相在 `scripts/work-order.js`。
- 相似标签只用**读者票**算余弦，共享 1 个标签即可上榜；不再用 `imageries` 兜底。
- 统计三层不许互相冒充：**到达**（上界/分母）→ **有效阅读**（下界）→ **读者**（跨天去重，只有它能回答"多少人"）。
- 投稿 PR 不修改任何共享登记文件；名单一律构建期从 `src/works/` 推导。
