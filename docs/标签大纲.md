## 二、机制（与讨论一致）

| 项 | 规则 |
|---|---|
| 权重 | **不加权**——关联度仍按标签向量的余弦归一，各类平权（讨论定：不用百分比权重） |
| 别名 | **不做自动吸附**——同义词由编委用「合并」动作处理（合并后票数并入目标词） |
| 自创标签 | 允许；表外词进"候选"，编委可采纳转正（进大纲）或合并/删除 |
| 限流 | **每设备每篇最多赞同 3 个标签**（取消不计数；服务端同时按 IP 兜底） |
| 手法类 | 与意象/情感/题材一样**开放给读者**（讨论定：开放） |

## 三、编委操作（网页内完成）

作品页 → 众注区右下「编委」→ 输入钥匙（CF 环境变量 `ZHUI_ADMIN_KEY`）：

- **初始化/更新标签词表**：把 94 词写入数据库（幂等，只增不改）；
- **整理历史标签**：按下方归并表把库里旧写法并入大纲词（幂等，只做一次）；
- 每个标签旁「⋯」：**采纳**（候选转正）/ **合并到某词**（票数并入）/ **删除**。

## 四、历史写法归并表（一次清洗，已执行）

`离别相思 / 思念 → 离愁`；`思乡归途 → 思乡`；`月星 → 月+星`；`月亮 / 明月 → 月`；`山水 → 山+水`；`江 → 水`；`花木 / 梅 → 花`；`凄冷 → 孤寂`；`累 → 忧郁`；`征人 → 怀人`；`修身 → 自省`；`高中 → 校园`；`棋局 → 棋`；`星际 → 星`；`春/夏/秋/冬/夜 → 春景/夏景/秋景/冬景/夜景`；`风物 → 弃用`。

## 五、维护约定

1. 改词表 → `npm run sync-tags`（生成 Worker 用模块）→ `npm test`（`test-tag-outline.js` 校验：无重复、释义齐全、作品意象都在大纲内）→ 推送 → 网页编委入口点一次"初始化/更新标签词表"；
2. 新词先进"候选"，由编委按社内偏好定期转正（"若大家多用『爱』，就把『爱』加进大纲"）；
3. 不用为找相似作品而硬造标签——特别有特点的词也可以加，编委定期整理即可。
