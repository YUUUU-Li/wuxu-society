# 网站投稿功能 · 简单说明版

> 一句话：社员在网站上填表投稿 → 系统自动生成一份"审稿单" → 你打开网页预览读一读 → 点一下"合并"就发布。
> 投稿的人不用学任何东西；**需要你动手的配置只有 2 步**（下面第二、三步），约 10 分钟，做完就一劳永逸。

---

## 一、普通社员怎么用（你不用教他们）

1. 打开网站 → 点「投稿」
2. 填：题名、署名、体裁、正文 → 提交
3. 完事。等审核结果（通过就自动上线，没过就重新提交）

## 二、审核人（你）每天怎么看稿

有投稿时，GitHub 仓库的 **Pull requests**（"审稿单"列表）里会出现一条，标题类似「投稿：秋望」：

1. 点开它，里面有一个 **预览链接**（形如 `https://deploy-preview-数字--wuxu-literary.netlify.app`）——点开就是在你们真网站上读这篇稿子的效果；
2. 觉得行：点 **Merge pull request**（合并）→ 自动发布上线；
3. 想改几个字：直接在审稿单里点开那个 `.md` 文件，铅笔图标编辑后保存；
4. 不收：点 **Close pull request**（关闭），在底下留言告诉作者原因。

> 看不懂英文没关系，就认两个按钮：绿色 **Merge** = 通过，灰色 **Close** = 退回。

## 三、需要你配置的两步（一次性，约 10 分钟）

### 第 1 步：创建一把"小钥匙"（GitHub Token）—— 8 分钟

它的作用：让网站投稿功能有权限往仓库里放文件。钥匙只对**这一个仓库**有效，随时可以作废重办，很安全。

1. 打开 <https://github.com>，登录；
2. 右上角你的**头像** → **Settings**（设置）；
3. 左侧拉到最下面 → **Developer settings**（开发者设置）；
4. 左侧 **Personal access tokens** → **Fine-grained tokens**（细粒度令牌）→ **Generate new token**（生成）；
5. 填：
   - Token name：随便写，比如 `wuxu-submit`
   - Expiration（有效期）：选 **12 months**（一年后记得重办）
6. **Repository access**：选 **Only select repositories** → 勾选 **wuxu-society**（只勾这一个！）
7. **Permissions**（权限）里找到两项，都改成 **Read and write**（读写）：
   - **Contents**
   - **Pull requests**
8. 页面最下面点 **Generate token**；
9. 出现一串以 `github_pat_` 开头的字符——**这是唯一一次显示，立刻复制**，关掉页面就再也看不到了。复制好先贴到记事本，下一步用。

### 第 2 步：把钥匙交给网站（存入 Netlify）—— 2 分钟

1. 打开 <https://app.netlify.com>，登录（就是管你们网站的那个账号）；
2. 点进你们的站点（名字带 `wuxu-literary` 的那个）；
3. 左侧 **Site configuration**（站点配置）→ **Environment variables**（环境变量）→ **Add a variable**；
4. 填两项：
   - Key：`GITHUB_TOKEN_SUBMIT`（照抄这个英文名）
   - Value：粘贴刚才那串钥匙
5. 保存。

> 完成这两步后告诉我一声即可，剩下（投稿页面、后台功能、说明文字）我来做。

## 四、小问答

- **这钥匙安全吗？** 安全。它只能动 `wuxu-society` 这一个仓库，不能碰你其他仓库和账号；万一泄露，到第 1 步的地方删掉重办一把就行。
- **以后要收费吗？** 不收费，GitHub 和 Netlify 的免费额度足够。
- **投稿会不会有垃圾？** 表单有防垃圾措施（隐藏陷阱字段 + 长度限制），而且每篇都要你人工看过才发布，垃圾进不来。
- **投稿人需要注册 GitHub 吗？** 不需要，任何人都能填表投。

## 五、附：技术上是怎么办到的（给想了解的人，可跳过）

投稿页把内容发给网站自带的一个小函数 → 函数用上面那把钥匙在 GitHub 自动生成一份"审稿单"（PR，含新作品的 `.md` 文件和作品库登记）→ GitHub 自动为它生成预览站 → 你点 Merge 后 Netlify 自动重新构建发布。全程复用你们已有的 GitHub + Netlify，**零新增费用、零服务器**。

- 仓库内计划新增文件：`src/submit.njk`（投稿页）、`netlify/functions/submit.mjs`（小函数）
- 前置：Netlify 构建配置 ✅ 已完成（Base directory 留空 / Build `npm run build` / Publish `dist`，新版已上线）
