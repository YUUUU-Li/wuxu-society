# 众注怎么用（给社员与读者）

> 网站作品页最下方有个「**众注**」区：给作品打标签、写评论。为了"每一票、每一条评论都算得清是谁的"，现在**打标签与评论需要先登录**（浏览不用登录，随便看）。

## 一、先注册（只要两样，约 20 秒）

1. 打开网站任意页面，点**右上角（导航栏最右）**的「**登录 / 注册**」（手机上先点右上角 ☰ 展开菜单）；
2. 切到**注册**，填**两样**：
   - **昵称**（就是你的署名，会显示在标签与评论旁 —— **社员请尽量用姓名缩写或笔名**，如 `jwl`、`蓦流`，方便大家认得；游客自拟即可）；
   - **口令**（至少 8 位）；
3. 点「注册并登录」→ 会弹出一串「**恢复码**」（形如 `4F2A-91C3-B7E5`）：**请自己存好**（截图或记在备忘录里）。换设备、忘记口令时，用它重设口令。

> 昵称**不能重复**（登录靠它认人）：若提示"这个昵称已经有人用了"，**加个后缀**即可（如「蓦流2」）。
> 没有社员审核、也不查名册——注册完就能用。

## 二、打标签（点一下即赞同，最多 3 个）

- 输入框里打字会**联想大纲词**（94 个词都带释义，鼠标悬停/手机长按可看解释）；
- 点已有的标签 = **赞同**（变**红**）；**再点一下 = 取消**（变灰，计数 −1）；
- **一首作品每人最多赞同 3 个标签**（取消一个就能再加一个）；
- 输入框里写一个词表里没有的词 = **自造标签**（会作为"候选"，等编委采纳后进正式词表）；
- 红色**只表示"你赞同过"**：刷新、换页面、换设备登录，颜色都不会变——这就是现在和以前最大的不同。

## 三、写评论

- 评论**必须登录**；署名**自动用你的昵称**（不用也不能手填）；
- 楼式平铺：点某楼的「回复」即在其下回复（回帖也是一楼）；行首加 `>` 可引原句或引他人评论；
- 点「**同感**」表示赞同某楼；**自己的评论不能给自己点同感**（那条按钮会变成不可点的计数）；
- 评论与同感都要登录后才可操作。

## 四、常见问题

| 问题 | 说明 |
|---|---|
| 忘了口令 | 用注册时那串**恢复码**重设（找编委亦可） |
| 换了手机/浏览器，之前投的票还认得吗 | **认得**——登录同一个昵称，你投过的标签仍然红、仍然可以取消 |
| 昵称被人用了怎么办 | 加个后缀即可（如「蓦流2」）；登录用的就是昵称，所以要唯一 |
| 想改昵称 | 目前找编委改（P2 会做自助修改） |
| 不想让人看到我赞同了哪些标签 | 现在**普通读者只看到票数**，看不到是谁；只有编委在编委模式下能看到名单（防刷票用） |
| 我是社员，需要谁审核吗 | **不需要**：注册即用，社员记得用姓名缩写/笔名当昵称就行 |

## 五、给编委的两句

- 编委用**账号**登录即自动获得管理入口（每词旁「⋯」、每楼「删」），不再需要共享钥匙；
- 把自己的账号升成编委：在 D1 控制台跑一句 `UPDATE users SET role='编委' WHERE nick_key='你的昵称';`（或让已有编委用 `role` 动作改）；开号/洗牌见《账号系统上线清单.md》。
