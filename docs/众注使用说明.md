# 众注怎么用（给社员与读者）

> 网站作品页最下方有个「**众注**」区：给作品打标签、写评论。为了"每一票、每一条评论都算得清是谁的"，现在**打标签与评论需要先登录**（浏览不用登录，随便看）。

## 一、先注册（约 30 秒）

1. 打开任意作品页 → 拉到最底部「众注」区 → 点右上角「**登录 / 注册**」；
2. 切到**注册**，填三样：**登录名**、**笔名**、**口令**（至少 8 位）；
3. 如果你是**社员**，勾上「**我是社员**」——勾了之后输入框会提示「请用名字缩写或笔名」，照着填（如登录名 `jwl`、笔名 `蓦流`）；
4. 点「注册并登录」→ 会弹出一串「**恢复码**」（形如 `4F2A-91C3-B7E5`）：**请自己存好**（截图或记在备忘录里）。换设备、忘记口令时，用它重设口令。

**游客（非社员）**同样可以注册，自拟笔名即可（推荐也用个像笔名的名字）。

> 为什么有些名字注册不了？社员的名字缩写与笔名（`jwl`、`蓦流`、`lfk`、`谰予`…）是**保留**的，防止有人冒名。如果你就是本人却注册不了，找编委开号。

## 二、打标签（点一下即赞同，最多 3 个）

- 输入框里打字会**联想大纲词**（94 个词都带释义，鼠标悬停/手机长按可看解释）；
- 点已有的标签 = **赞同**（变**红**）；**再点一下 = 取消**（变灰，计数 −1）；
- **一首作品每人最多赞同 3 个标签**（取消一个就能再加一个）；
- 输入框里写一个词表里没有的词 = **自造标签**（会作为"候选"，等编委采纳后进正式词表）；
- 红色**只表示"你赞同过"**：刷新、换页面、换设备登录，颜色都不会变——这就是现在和以前最大的不同。

## 三、写评论

- 评论**必须登录**；署名**自动用你的笔名**（不用也不能手填，避免冒名）；
- 楼式平铺：点某楼的「回复」即在其下回复（回帖也是一楼）；行首加 `>` 可引原句或引他人评论；
- 点「**同感**」表示赞同某楼；**自己的评论不能给自己点同感**（那条按钮会变成不可点的计数）；
- 评论与同感都要登录后才可操作。

## 四、常见问题

| 问题 | 说明 |
|---|---|
| 忘了口令 | 找编委，或用注册时那串**恢复码**重设（P2 会做自助重设界面） |
| 换了手机/浏览器，之前投的票还认得吗 | **认得**——登录同一账号，你投过的标签仍然红、仍然可以取消 |
| 能用别人的名字注册吗 | 社员的缩写/笔名已被保留；其他昵称也唯一，撞名会被拒 |
| 想改笔名 | 目前找编委改（P2 会做自助修改） |
| 不想让人看到我赞同了哪些标签 | 现在**普通读者只看到票数**，看不到是谁；只有编委在编委模式下能看到名单（防刷票用） |
| 我注册了但没显示"社员" | 勾了"我是社员"的账号是**待编委确认**状态，编委核对后会给你社员身份 |

## 五、给编委的两句

- 编委用**账号**登录即自动获得管理入口（每词旁「⋯」、每楼「删」），不再需要共享钥匙；
- 待确认社员 / 开号 / 改角色走 `scripts/zhuzhu-admin.py`（见《账号系统上线清单.md》第 3、5 节）。
