# 修改网站 · Git 速查

> 给维护网站的同学：改完 → 本地验证 → 提交 → 推送，**推 main 即自动发布**（Netlify 自动构建，1~3 分钟）。
> 仓库：<https://github.com/YUUUU-Li/wuxu-society>

## 第一步：把仓库弄到本地

```bash
git clone https://github.com/YUUUU-Li/wuxu-society.git
```

已有本地仓库的话，直接更新到最新：

```bash
cd 你的仓库路径        # 例：cd D:/wuxu-society
git pull
```

## 第二步：开个分支（可选，大改动才需要）

```bash
git checkout -b dev        # 新建并切换到 dev 分支
git branch                 # 查看当前在哪个分支（带 * 的就是）
```

> 小修小改可以跳过这步，直接在 main 上改完就推（推 main = 网站自动更新）。
> 分支名别用中文和空格。

## 第三步：快乐 vibe coding ✍️

改完先本地验证一遍：

```bash
npm run build              # 构建检查（没错才能生成 dist/）
npm run serve              # 本地预览 → 浏览器开 http://localhost:8080
```

本仓库的规矩：

- 作品内容在 `src/works/*.md`；**新增作品**还要把文件名（不含 `.md`）加进 `src/_data/groups.json` 的 `slugs`（见 [作品上传指南](作品上传指南.md)）；
- `dist/`、`node_modules/` 是构建产物，**别去动**（已 gitignore，不会提交）；
- 社员名单在 `src/_data/members.json`；导航/页脚在 `src/_includes/`。

## 第四步：提交修改

```bash
git status                 # 先看改了哪些文件
git add 具体文件或 .        # 例: git add src/works/w-qiuwang.md
git commit -m "说明改了什么，如: 新增 zk 五律《秋望》"
```

> 提交说明写清楚"干了什么"：新增 / 改字（fix）/ 删稿，例：`fix: 修正《风》第二句错字`。

## 第五步：合并分支（用了 dev 分支才需要）

```bash
git checkout main          # ① 先回到 main！
git pull                   # ② 拉最新，减少冲突
git merge dev              # ③ 把 dev 并进 main
```

> 一直在 main 上改的同学跳过这步。

## 第六步：推送发布

```bash
git push origin main       # 推 main → Netlify 自动重新构建，1~3 分钟后线上更新
```

> push 只推**当前所在分支**；确认在 main 上再推。

## 反悔药 💊

```bash
git restore 文件名          # 还没提交：放弃这个文件的改动
git reset --soft HEAD~1     # 刚提交完：撤销最近一次提交（改动保留）
git pull --rebase           # push 被拒（别人先推了）时先执行这个，再 push
```

国内网络卡时配一次代理（以后所有 GitHub 操作自动生效）：

```bash
git config --global http.https://github.com.proxy http://127.0.0.1:7890
```
