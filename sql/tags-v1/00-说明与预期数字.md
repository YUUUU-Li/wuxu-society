# 标签落库：一条语句一个文件（给 D1 控制台用）

> 为什么要这么拆：Cloudflare D1 控制台**一次只认一条语句**。整段粘会像成功却没执行（第一轮）或多条里只生效一条（第二轮，只有那句单独的 UPDATE 生效了）。

## 用法（每条都一个文件）

1. 打开某个文件 → `Ctrl+A` 全选 → `Ctrl+C`；
2. 粘进 Cloudflare → D1 → `wuxu-database` → **Console** → 点执行；
3. 跑完按文件里写的「期望」对一眼数字（`10-核对-词数.sql` 随时可跑）。

**一次只粘一个文件，不要几个文件合起来粘。**
